# Tamaa Music Android build

Builds a GPL-3.0 fork of [InterTune](https://github.com/ItzSkyeYT/InterTune) using the pinned upstream commit and `tamaa-customize.patch`. Credits: InterTune, OuterTune, InnerTune. This repository is a build workspace for Tamaa Music.

The build workflow produces an installable debug APK in the Actions artifact. Full source is reconstructed by the workflow from the pinned upstream commit plus the patch. See LICENSE and source notices in upstream and patch.
